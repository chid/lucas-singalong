# Lucas — Sing & Explore
Buildless song library with 11 official song links, suggested vocabulary, play prompts, topic filters, search and browser-local favourites. Original recordings and lyrics are not copied.

Serve `dist` with any static web server. Deploy `dist/` to GitHub Pages or g2. No dependencies or build step.

Sources checked 17 November 2026. Suggested words include related play vocabulary; they are not lyric transcriptions. Video playback requires internet. Saved favourites are per browser and origin, without backup/sync.
